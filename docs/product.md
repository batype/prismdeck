# 交付范围

PrismDeck 是未来感 UI 组件实验工作台：选择组件 → 调校主题 → 操作预览 → 导出 React + CSS。面向希望快速试验产品视觉风格的前端开发者。

三个组件：SpatialCard、OrbitDial、CommandDock。统一色彩与材质配置，支持亮暗材质、颜色、圆角、光晕、动效与卡片网格。参数本地保存，支持配置 JSON 导入导出与 URL 分享。

设计方向：石墨、荧光绿、精细轨道、坐标、克制的网格和层次。持续动效不承担业务逻辑；用户有减少动态效果偏好时保持基本操作。

核心实现为自有 React + CSS，不复制第三方组件实现。现有 Aceternity / React Bits 等方案说明此类 UI 有成熟先例，不将“未来感”描述成市场独占创新，也不承诺流量。

导出 ZIP 为可接入已有项目的源码片段，包含三个原语及当前选中组件示例；npm 包为可安装的 React 组件库。既有用户项目不需要采用工作台页面布局。

演示方案：切换空间卡片 → 改为离子紫 → 调节光晕和圆角 → 切换轨道旋钮并拖动 → 查看代码 → 下载 ZIP。
