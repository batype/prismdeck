## 浏览器人工回归

桌面 1440×900 与手机 390×844：

1. 仪表盘切换示例：72 → 35，标题改为“处理延迟”，单位改为 ms；图形和原生 meter 数值同步。
2. 查看 React 代码：chart.value 为 35，title 和 unit 使用当前设置。
3. 查看配置 JSON：保留同样的标题、单位、范围和值。
4. 当前数值先调到 100，再通过由真实配置 JSON 构成的分享链接恢复：回到 35、处理延迟、ms。
5. 数据编辑器应用错误类型 value="bad"：显示错误，原图仍为有效的旧数据。
6. 应用 0.0001 / 0.0002：纵轴显示 0.0002、0.00015、0.0001、0.00005、0；读数保留精度。
7. 手机“调校”页面可使用图表专属字段；切换亮色材质再返回预览，数值仍为 35。
8. 旧版不包含 charts 字段的分享链接仍正常载入旋钮，值为 64。

## 能力边界

- 数据 JSON 必须先“应用”；未应用文本草稿不保存或导出。
- 分享链接是创建时的快照，打开该链接会优先载入链接配置；普通页面刷新恢复浏览器保存的设计。
- 通用控件的临时点击次数、弹窗打开状态等不作为设计配置导出。
- 本次保留既有公共 API，未增加多系列图表或改造卡片/旋钮的业务 API。
- 浏览器交互为人工回归；CI 运行输出、类型、核心模型和导出编译测试，尚未引入浏览器自动化依赖。
- 开发入口历史 HMR 重复 createRoot 警告没有在本次扩大范围修复；生产站点另行核实。
